Agent-Definitionen auflisten, anzeigen, prüfen und anlegen

Usage: beton agent [OPTIONS] <COMMAND>

Commands:
  list      Agents im Suchpfad: Projekt, User, Built-ins (Name, Quelle, Version, Harness, Pfad)
  show      Aufgelösten Agent mit Herkunft jedes Felds und Inhalts-Hash anzeigen
  validate  Agent gegen Schema und semantische Regeln prüfen; Exit 0 gültig, 1 Fehler
  new       Gerüst unter `.beton/agents/<NAME>/` anlegen (mit `$schema`-Kommentar, Prompt, Skill)
  schema    JSON-Schema des Agent-Formats ausgeben

Options:
      --server <URL>
          Server-URL statt des lokalen Daemons (Token aus `BETON_TOKEN`)
          
          [env: BETON_SERVER]

      --json
          Maschinenlesbare Ausgabe (JSON) auf stdout

  -q, --quiet
          Keine Fortschritts- und Hinweismeldungen auf stderr

  -v, --verbose...
          Mehr Diagnose auf stderr (mehrfach: noch mehr)

      --no-color
          Keine Farben (auch über `NO_COLOR`)

      --config <FILE>
          User-Konfiguration aus dieser Datei statt `~/.beton/config.yaml`

  -h, --help
          Print help

  -V, --version
          Print version
