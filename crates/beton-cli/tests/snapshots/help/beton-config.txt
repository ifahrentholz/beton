Konfiguration lesen und schreiben

Usage: beton config [OPTIONS] <COMMAND>

Commands:
  get    Effektiven Wert eines Schlüssels ausgeben
  set    Wert setzen (Default: User-Konfiguration)
  unset  Wert entfernen
  list   Effektive Konfiguration mit Herkunft je Schlüssel
  edit   Konfigurationsdatei im Editor öffnen und danach prüfen

Options:
      --server <URL>
          Server-URL statt des lokalen Daemons (Token aus `BETON_TOKEN`)
          
          [env: BETON_SERVER]

      --json
          Maschinenlesbare Ausgabe (JSON) auf stdout

  -q, --quiet
          Keine Fortschritts- und Hinweismeldungen auf stderr

  -v, --verbose...
          Mehr Diagnose auf stderr (mehrfach: noch mehr)

      --no-color
          Keine Farben (auch über `NO_COLOR`)

      --config <FILE>
          User-Konfiguration aus dieser Datei statt `~/.beton/config.yaml`

  -h, --help
          Print help

  -V, --version
          Print version
