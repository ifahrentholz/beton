Modell von der im Programm hinterlegten Adresse laden und per SHA-256 prüfen. Fragt vorher nach;
ohne Terminal nur mit `--yes`. Abgebrochene Downloads setzt ein neuer Aufruf fort

Usage: beton voice models pull [OPTIONS] <MODELL>

Arguments:
  <MODELL>
          Modellname, z. B. `small` oder `large-v3-turbo` (siehe `beton voice models list`)

Options:
      --server <URL>
          Server-URL statt des lokalen Daemons (Token aus `BETON_TOKEN`)
          
          [env: BETON_SERVER]

  -y, --yes
          Ohne Rückfrage laden (Zustimmung zum Download)

      --json
          Maschinenlesbare Ausgabe (JSON) auf stdout

  -q, --quiet
          Keine Fortschritts- und Hinweismeldungen auf stderr

  -v, --verbose...
          Mehr Diagnose auf stderr (mehrfach: noch mehr)

      --no-color
          Keine Farben (auch über `NO_COLOR`)

      --config <FILE>
          User-Konfiguration aus dieser Datei statt `~/.beton/config.yaml`

  -h, --help
          Print help

  -V, --version
          Print version
