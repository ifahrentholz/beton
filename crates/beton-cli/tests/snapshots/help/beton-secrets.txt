Secrets verwalten (API-Keys, Tokens); Werte werden nie angezeigt

Usage: beton secrets [OPTIONS] <COMMAND>

Commands:
  add     Secret anlegen; den Wert verdeckt am Terminal eingeben, über `--stdin` oder `--from-file`,
          nie als Argument
  list    Secrets auflisten (Ref, Typ, Provider, Account, zuletzt genutzt); nie Werte
  rm      Secret entfernen (Wert im Keychain bzw. in der Datei und Metadaten)
  rotate  Neuen Wert für ein vorhandenes Secret setzen
  unlock  Verschlüsselten Datei-Store entsperren (beim ersten Mal anlegen) oder die Passphrase
          wechseln

Options:
      --server <URL>
          Server-URL statt des lokalen Daemons (Token aus `BETON_TOKEN`)
          
          [env: BETON_SERVER]

      --json
          Maschinenlesbare Ausgabe (JSON) auf stdout

  -q, --quiet
          Keine Fortschritts- und Hinweismeldungen auf stderr

  -v, --verbose...
          Mehr Diagnose auf stderr (mehrfach: noch mehr)

      --no-color
          Keine Farben (auch über `NO_COLOR`)

      --config <FILE>
          User-Konfiguration aus dieser Datei statt `~/.beton/config.yaml`

  -h, --help
          Print help

  -V, --version
          Print version
