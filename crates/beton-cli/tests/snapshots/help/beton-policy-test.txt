Deklarative Policy-Tests (`*.policytest.yaml`) ausführen; Exit 0 bestanden, 1 Fehlschlag

Usage: beton policy test [OPTIONS] [PATH]...

Arguments:
  [PATH]...
          Testdateien oder Verzeichnisse (rekursiv); Default `.beton/policies/tests/`

Options:
      --junit <FILE>
          Ergebnis zusätzlich als JUnit-XML schreiben

      --server <URL>
          Server-URL statt des lokalen Daemons (Token aus `BETON_TOKEN`)
          
          [env: BETON_SERVER]

      --json
          Maschinenlesbare Ausgabe (JSON) auf stdout

  -q, --quiet
          Keine Fortschritts- und Hinweismeldungen auf stderr

  -v, --verbose...
          Mehr Diagnose auf stderr (mehrfach: noch mehr)

      --no-color
          Keine Farben (auch über `NO_COLOR`)

      --config <FILE>
          User-Konfiguration aus dieser Datei statt `~/.beton/config.yaml`

  -h, --help
          Print help

  -V, --version
          Print version
