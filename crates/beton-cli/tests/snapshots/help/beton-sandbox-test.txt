Selbsttests der Sandbox-Backends dieser Plattform (die Fälle der Probe) ausführen. Pflicht ist das
Backend, das eine Session hier nähme (`sandbox.backend`, sonst `auto`); Exit 0 nur, wenn es
bestanden hat. Die vollständige Escape-Suite läuft als Tests aus dem Quellbaum (SBX-011)

Usage: beton sandbox test [OPTIONS]

Options:
      --server <URL>
          Server-URL statt des lokalen Daemons (Token aus `BETON_TOKEN`)
          
          [env: BETON_SERVER]

      --json
          Maschinenlesbare Ausgabe (JSON) auf stdout

  -q, --quiet
          Keine Fortschritts- und Hinweismeldungen auf stderr

  -v, --verbose...
          Mehr Diagnose auf stderr (mehrfach: noch mehr)

      --no-color
          Keine Farben (auch über `NO_COLOR`)

      --config <FILE>
          User-Konfiguration aus dieser Datei statt `~/.beton/config.yaml`

  -h, --help
          Print help

  -V, --version
          Print version
