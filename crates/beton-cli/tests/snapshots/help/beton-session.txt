Sessions verwalten

Usage: beton session [OPTIONS] <COMMAND>

Commands:
  list       Sessions auflisten
  show       Details einer Session
  rename     Session umbenennen
  archive    Session archivieren (Runner stoppt)
  unarchive  Archivierte Session wiederherstellen
  delete     Session endgültig löschen (entfernt ihren Worktree kontrolliert)
  interrupt  Laufenden Turn abbrechen

Options:
      --server <URL>
          Server-URL statt des lokalen Daemons (Token aus `BETON_TOKEN`)
          
          [env: BETON_SERVER]

      --json
          Maschinenlesbare Ausgabe (JSON) auf stdout

  -q, --quiet
          Keine Fortschritts- und Hinweismeldungen auf stderr

  -v, --verbose...
          Mehr Diagnose auf stderr (mehrfach: noch mehr)

      --no-color
          Keine Farben (auch über `NO_COLOR`)

      --config <FILE>
          User-Konfiguration aus dieser Datei statt `~/.beton/config.yaml`

  -h, --help
          Print help

  -V, --version
          Print version
